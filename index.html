새 시험지 등록

캐치유테스트는 매주 금요일에 봐요. 학년마다 시험지가 다르니, 학년을 선택하고 그 학년의 시험지를 업로드하세요. 같은 학년에 다른 시험지의 경우, 추가 업로드 하면 됩니다.

총 문항 수
아직 업로드된 시험지가 없어요.
시험지 이름 (업로드하면 파일명으로 자동 입력, 직접 수정 가능)

시험지를 업로드한 뒤 버튼을 누르면 AI가 문항별 유형 · 2022 개정 교육과정 단원 · 핵심역량 · 난이도를 자동으로 분석해요.

API 키가 없어요 (Claude 채팅으로 대신 분석)

위 시험지를 Claude 채팅창에 올려 "문항별 유형 분석해줘"라고 요청하면, 같은 형식의 JSON을 만들어드려요.

유형 확인 · 수정 (AI 분석 결과가 여기 들어와요)

시험지 분석 파일 가져오기

채팅에 시험지를 올려서 Claude에게 분석해달라고 하면, 유형·난이도가 채워진 파일을 만들어줘요. 그 파일을 여기로 불러오면 새 시험지는 추가되고, 이미 있는 시험지는 내용만 갱신돼요 — 다른 시험지·학생·채점 기록은 전혀 지워지지 않아요.

백업 · 이전

이 프로그램의 데이터는 이 컴퓨터의 이 브라우저에만 저장돼요. 다른 컴퓨터로 옮기거나 백업하려면 내보내기 파일을 사용하세요.
내보내기/가져오기에 포함되는 것: 학생 명단(이름·학교·학년·반·담당 선생님), 회차·시험지 정보, 학생별 채점 기록(누가 몇 회차에서 몇 번을 틀렸는지), 재시험 기록, 선생님이 작성한 보고서 의견 — 즉 이 화면에 있는 데이터 전부예요.
가져오기는 지금 있는 데이터를 전부 덮어써요 (병합이 아니라 완전히 교체). API 키는 포함되지 않아요.

학생 명단 추가 (병합)

명단 파일을 불러오면 기존 데이터를 지우지 않고 새 학생만 추가돼요 (이름+반이 같으면 중복으로 보고 건너뜀).

공용 회차 공유 (관리자용)

회차(날짜·학년·문항 유형·단원·난이도·역량)만 따로 내보내서 모든 선생님 컴퓨터에 자동으로 뿌릴 수 있어요. 시험지 원본 이미지는 포함되지 않아요. 내보낸 파일을 Claude에게 전달해서 GitHub에 올려달라고 하면, 다음부터 모든 선생님 화면에 이번 회차가 자동으로 나타나요 (각자 등록할 필요 없음).

예시 데이터

프로그램이 처음이라면 예시 데이터를 불러와 기능을 먼저 살펴보세요. (기존 데이터가 있으면 백업 후 사용하세요)

전체 초기화

모든 학생·회차·채점 기록을 삭제합니다. 되돌릴 수 없어요.

API 키 설정

console.anthropic.com에서 발급받은 API 키를 입력하면, 회차·시험지 탭에서 "AI로 자동 분석" 버튼으로 문항을 바로 분석할 수 있어요. 이 컴퓨터에만 저장되고, 백업 파일에는 포함되지 않아요.
