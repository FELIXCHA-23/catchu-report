KMMS

(KASTLE MATH MANAGEMENT SYSTEM)

담당 선생님과 메뉴를 선택하십시오.

KMMS 앱 받기 (Windows)설치하면 재시험지가 인쇄 창 없이 바로, 스테이플까지 출력돼요

교재 채점 및 분석

분석 범위 번부터 번까지 범위 내 문제는 전부 푼 것으로 처리하고, 입력한 번호만 오답으로 계산.

틀린 번호 입력

틀린 문제 번호만 누적 입력. 정답률은 분석·보고서에서 지정한 범위로 계산.

파일이나 표로 한꺼번에 올리기

지원 형식: txt, xlsx, csv (구글 시트는 엑셀 또는 csv로 내려받아 사용). 표에서 복사해 아래에 붙여넣기도 가능.
작성 방법: 한 줄에 한 학생, 이름 + 틀린 번호. 예) 김민수 14, 20~25, 31 이름이 가로, 번호가 세로인 표도 가능. 이름은 학생 관리의 등록 이름과 일치해야 하며 반·번호 등 다른 숫자는 제외.

파일을 끌어다 놓거나 클릭해서 선택
txt · csv · xlsx · xls

학생 관리

학생 등록

이름, 학년, 반, 담당 선생님을 입력.

학생 목록

상단에서 담당 선생님을 선택하면 해당 학생만 표시 (미선택 시 전체).

학생 명단

가져오기: 기존 데이터는 유지하고 새 학생만 추가 (이름+반이 같으면 중복으로 건너뜀). 내보내기: 이름·학교·학년·반·담당 선생님만 저장하며, 다른 컴퓨터에서 그대로 가져오기 가능.

구글 시트 · 엑셀로 명단 올리기

구글 시트: 파일 → 다운로드 → 엑셀(.xlsx) 후 업로드하거나, 칸을 복사해 아래에 붙여넣기. 첫 줄에 이름 · 학교 · 학년 · 반 · 담당 · 상태(또는 비고) 제목이 있으면 해당 열을 읽고, 없으면 이 순서로 읽음. 새 학생은 추가, 기존 학생은 학교·학년·반·담당 갱신, 상태가 "퇴원"이면 숨김 처리. 반영 전 미리보기 제공.

명단 파일을 끌어다 놓거나 클릭해서 선택
xlsx · xls · csv · txt

시험지 등록

본시험지

캐치유테스트는 매주 금요일 실시. 학년별로 시험지를 업로드하며, 같은 학년에 다른 시험지가 있으면 추가 업로드.

총 문항 수
업로드된 시험지 없음. 버튼 클릭 또는 이 영역에 파일을 끌어다 놓기.
시험지 이름 (업로드 시 파일명으로 자동 입력, 수정 가능)

시험지 업로드 후 실행하면 문항별 유형 · 2022 개정 교육과정 단원 · 핵심역량 · 난이도를 AI가 분석.

API 키 없이 분석 (Claude 채팅 이용)

시험지를 Claude 채팅창에 올려 문항별 유형 분석을 요청하면 같은 형식의 JSON 파일이 생성됨.

유형 확인 · 수정 (AI 분석 결과 표시)

재시험지

회차를 고른 뒤 재시험지 PDF를 올림(본시험지 없이 새로 올려도 됨). 정답(빠른정답)은 재시험지 맨 뒤에 붙여서 같이 올리면 됨. 유형 분석은 하지 않음.

시험지 분석 파일 가져오기

Claude 채팅에서 분석한 시험지 파일(유형·난이도 포함)을 가져옴. 새 시험지는 추가, 기존 시험지는 내용만 갱신하며 다른 시험지·학생·채점 기록은 삭제되지 않음.

시험지 보기

분석 요청으로 올라온 시험지 (아직 회차로 저장되지 않음)

이번 주 시험지 업로드 현황

시험지 파일을 이 화면 어디에나 끌어다 놓으세요 (놓으면 본시험지인지 재시험지인지 물어봐요)

부터 까지 회차만 표시

오답 순위

시험지(학년)별로 가장 많이 틀린 문항을 오답 인원수 순으로 보여줘요. 문항을 누르면 그 문제가 떠요. "주차 범위"를 고르면 몇 주차부터 몇 주차까지 전체를 합쳐서 봐요.

부터까지

재시험 채점

원 회차의 오답 문항만 쌍둥이문제로 재시험. 다시 틀린 문항만 클릭.

학생별 재시험 채점 현황

오답이 있는 회차마다 재시험을 쳤는지 한눈에 확인. 재시험만 따로 기간을 정해서 볼 수 있음 (채점 입력 탭의 기간과 별개).

백업 · 이전 (관리자용)

데이터는 서버에 자동으로 저장되고 모든 선생님이 같이 씀. 그래서 백업 파일을 자동으로 받거나 따로 가져올 필요는 없고, 이 기능은 만일을 위한 관리자용 보관·복원 도구임.
포함 항목: 학생 명단, 회차·시험지 정보, 학생별 채점 기록, 재시험 기록, 보고서 의견, 교재 채점 기록과 교재 보고서 의견·PDF 포함 설정, 평균 난이도 조절 값.
가져오기는 기존 데이터를 전부 교체하고 그 결과가 서버와 모든 선생님 화면에 반영되므로 꼭 필요할 때만 쓸 것. API 키는 포함되지 않음.

공용 회차 공유 (관리자용)

회차 정보(날짜·학년·문항 유형·단원·난이도·역량)만 내보내 모든 선생님 컴퓨터에 공유. 시험지 원본 이미지는 제외. 내보낸 파일을 GitHub에 올리면 이후 모든 선생님 화면에 해당 회차가 자동 표시됨.

예시 데이터

예시 데이터를 불러와 기능을 확인. 기존 데이터가 있으면 백업 후 사용.

전체 초기화

모든 학생·회차·채점 기록을 삭제함. 되돌릴 수 없음.

시험지 자동 공유 (GitHub)

토큰 입력 시 시험지 탭에서 회차를 저장하면 모든 선생님 화면에 자동 반영 (1~2분 소요). 유형·단원·난이도만 공유하며 시험지 이미지와 학생 정보는 제외. 토큰은 이 컴퓨터에만 저장되고 백업에 포함되지 않음. 토큰이 없으면 이 컴퓨터에만 저장.

API 키 설정
